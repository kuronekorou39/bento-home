# 段階4 使用頻度の反映 — 実機確認の記録

記録日: 2026-10-26（日本時間）  
端末: Pixel 9a / Android 17（CP3A.260905.009）。端末の詳細は `docs/spike-notes.md`。  
対象: `com.rou39.bentohome.debug`。操作は adb の入力イベントで行った。

## 確認の方法

グレー表示は、観測開始や最終起動から30日たたないと出ない。確認のため、アプリを止めた状態で DB を PC へ取り出し、2つのアプリの観測開始を40日前に書き換えて戻した。確認の最後に設定の「使用履歴を削除」を実行し、書き換えた値と確認中の起動記録をまとめて消した。PC に取り出した DB の控えも削除した。

## 結果

| 項目 | 結果 | 備考 |
|---|---|---|
| DB の v2→v3 移行 | 合格 | 自動マイグレーションで `usage_daily`・`usage_summary` を追加。配置は残った |
| 観測開始の記録 | 合格 | 起動直後に 176 アプリすべての観測開始が入った |
| 起動回数の記録 | 合格 | 一覧から起動すると、日別件数と最終起動が記録された |
| よく使う順 | 合格 | 起動したアプリが先頭に並び、残りは名前順 |
| 最近開いた順 | 合格 | 最後に起動したアプリが先頭に移る |
| グレー表示 | 合格 | 観測40日・未起動のアプリは彩度を落とし、70% の濃さで描く |
| グレーの理由表示 | 合格 | 長押しで「観測を始めて40日、このランチャーでは未起動」と出る |
| 起動で色が戻る | 合格 | グレーのアプリを起動すると、次に一覧を開いたとき通常の色に戻る |
| 使用履歴の削除 | 合格 | 確認ダイアログの後、日別件数と最終起動を消し、全アプリの観測開始を今日にした |

## 気づいた点

- ABEMA のアイコンはもともと白黒なので、彩度を落としても見分けにくい。濃さを 70% にしているので、白い部分の明るさで判別できる。
- 1回だけ、グレー判定のアプリが通常の色で描かれた。アプリを止めて開き直す確認を2回したが、再現しなかった。DB を書き戻した直後のタイミングによるものと見ている。
- 一覧の長押しメニューでは、グレーの理由が「ホームに追加」の下に出る。ホームとドックでは先頭に出る。
- 再インストールの直後にホームキーを押すと、ホームアプリの選択画面が出ることがある。段階3でも同じことが起きた。既定ホームのロールは保たれている。

## 実装しなかったもの

- plan.md §2 の「よく使う」領域。頻度順は一覧の並び替えで提供し、ホームやドックの手動配置は動かさない。
- Android 全体の利用状況（UsageStatsManager）の参照。plan.md §4 のとおり初版では必須にしていない。
