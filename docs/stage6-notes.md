## 1. フォルダー

### 使い方

- アプリを、ホームの別のアプリの上に重ねて離すとフォルダーになる。フォルダーの上に離すと中に足す。ホーム・ドック・アプリ一覧・別のフォルダーのどこから運んでも同じ。
- 重ねる判定は、指が相手の項目の中ほど（端から2割を除いた範囲）にあるときだけ。端の近くは普通の移動として扱い、隣に並べて置けるようにする。置き先の枠は、まとめるときは相手の項目の範囲に出る。
- タップで画面の中央に開く。外側のタップか戻る操作で閉じる。
- 名前は、開いたフォルダーの名前をタップして変える。開いたときは名前全体を選んだ状態にし、確定キーを押さずに閉じても入力した名前を残す。空にすると「フォルダー」に戻る。
- 中のアプリ: タップで起動、長押しでメニュー（ショートカット・アプリ情報・アンインストール・外観の個別設定・フォルダーから出す）、長押しのまま動かすとホームやドックへ運べる。運んでいる間はフォルダーを透明にして、指の操作が途切れないよう残す。
- ホームのフォルダーを長押しすると「開く」「名前を変更」「ホームから削除（中のアプリも）」。
- 中が1つになったらアプリに戻し、空になったら消す。アンインストールしたアプリは中からも外す（停止中に消えたアプリも起動時に外す）。
- バッジは中のアプリをまとめる。件数があれば合計、点だけなら点。
- 配置ロック中は、開いて起動することと名前の変更だけできる。
- すべての配置の変更は、これまでどおりスナックバーの「元に戻す」で取り消せる。

### 決めたこと

- フォルダーの中にフォルダーは入れない。フォルダーはドックに置けない（ドックはアプリだけを持つ）。
- 同じアプリを2回入れない。
- 見た目は角丸の半透明の下地に、先頭4つのアプリを小さく並べる。開いた画面は1行4つ。

### 構成

| 部品 | 内容 |
|---|---|
| `ItemContent.Folder` | 名前と中のアプリの並び |
| `LayoutEngine` | `mergeInto`・`removeFromFolder`・`renameFolder`・`removeApps`・`normalizeFolders`（単体テスト `FolderTest`） |
| `DragSource.FolderApp`・`DropTarget.Merge` | フォルダーから運ぶ、重ねてまとめる |
| `HomeController.mergeTarget` | 指の位置から、まとめ先を決める |
| `FolderUi.kt` | フォルダーのアイコン、ホームのフォルダー、開いたフォルダー |
| Room v4 | `workspace_item.title` と `folder_app`。v3 から自動マイグレーション |
| バックアップ v2 | `BackupItem` に `title`・`apps`。この端末に無いアプリは除き、1つ以下になったらアプリに戻す |

| アプリ一覧から運んで、ホームのアプリに重ねる | 合格。同じ位置にフォルダーができる |

| タップで開く、外側で閉じる | 合格 |

## 2. ホーム画面に追加

### 使い方

- Chrome の「ホーム画面に追加」→「ショートカットを作成」など、他のアプリがショートカットやウィジェットの追加を頼むと、Bento の確認画面が呼び出し元の上に出る。「追加」でホームの空いている場所（表示中のページから探す）に置く。
- 置いたショートカットは、タップで開き、長押しで「提供元のアプリ情報」「ホームから削除」、長押しのまま動かすと移動。
- 提供元がショートカットを消した・無効にしたときは「?」で表示し、タップすると理由を出す。
- フォルダーとドックには入れない（どちらもアプリだけを持つ）。

### 決めたこと

- 確認画面は独立した作業グループで開く（`taskAffinity=""`）。ホームの作業グループに入れると、背後に前のホーム（Pixel Launcher）が透けた。
- 受け入れた項目はチャンネルで渡し、ホームが配置を読み込んでから置く。
- ホームから外したショートカットは、取り消しの猶予が過ぎてから（次の配置の変更のとき）OS 側の固定も外す。すぐ外すと、提供元によっては OS がショートカットを消し、取り消しても戻らないため。プロセスが途中で終わった場合に備え、起動時に OS 側の固定と配置を突き合わせて、配置に無いものを外す。
- ウィジェットの追加依頼は、ID を割り当てて許可を得てから提供元に渡す（許可が要るときはウィジェットの追加と同じ画面を出す）。
- バックアップ v3 でショートカットを書く。読み込むと提供元が入っていれば戻す（開けるかは提供元が持っているか次第）。
- Room v5 で `workspace_item.shortcutId` を足した。

### 実機の確認

| 項目 | 結果 |
|---|---|
| Chrome の「ショートカットを作成」→ Bento の確認画面 | 合格。Chrome の上に出る |
| 「追加」でホームに置く | 合格。Chrome に戻り、ホームの空いている場所に置かれる |
| タップで開く | 合格。Chrome でそのページが開く |
| ホームから削除したときの OS 側の固定 | 合格。次の配置の変更で外れる。プロセスが終わっていた場合も起動時に外れる（`dumpsys shortcut` で確認） |
| ウィジェットの追加依頼 | 未確認（依頼を出すアプリが手元に無い） |

確認のために置いたショートカットは削除し、OS 側の固定も外れたことを確かめた。

### 気づいた点

- 開発中に APK を入れ直すと（新しい画面を足したときなど）、ホームの役割は Bento のままなのに、ホームキーで「ホームアプリを選択」が出ることがあった。「Bento Home」と「常時」を選べば戻る。
